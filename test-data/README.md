# Data files used in the test suite

This directory contains data files used as part of this crate's test suite:

* **`trusted-roots/sigstore.json`**  
  List of trusted roots of Sigstore's public benefit instance. 
  [Download URL](https://github.com/sigstore/root-signing/raw/refs/heads/main/targets/trusted_root.json)

* **`attestations/hello-world`**  
  **`attestations/hello-world.sigstore.json`**  
  Attestation signed by Sigstore's public benefit instance of a file containing
  `hello world\n`, signed with Emily's work Google Account.
